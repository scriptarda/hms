# Healthcare Enterprise Management System (HEMS) - Project Roadmap

## Phase 1: Authentication & Core Layout
- Login Page (SSO, MFA)
- Main Application Shell (Collapsible Sidebar, Global Search, Notifications)
- User Profile Setup

## Phase 2: Staff Experience (Reporting & Requests)
- Staff Dashboard (Personalized Overview)
- Service Catalog (Requesting Equipment/Access)
- Create Incident Form (Multi-step with Asset Linkage)
- My Requests/Incidents List

## Phase 3: Technician Workspace (Fulfillment)
- Technician Dashboard (Work Queue, SLA focus)
- Ticket Assignment Board (Kanban)
- Incident Details & Resolution Workflow
- Mobile Technician View (Field Work)

## Phase 4: Asset & Maintenance Management
- Asset Registry (Table view with Filters)
- Asset Details (Lifecycle & History)
- Maintenance Calendar (Preventive Scheduling)
- QR Code Reporting (Mobile-first)

## Phase 5: Administration & Analytics
- Executive Dashboard (KPIs, SLA Compliance)
- User & Department Management
- Approval Workflow Builder
- System Settings (SLA & Branding)

## Phase 6: Support & Knowledge
- Knowledge Base Home
- Article View
- Inventory Management (Spare Parts)
- Major Incident Command Center
